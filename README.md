# REBUS in Silico

The public page of an interactive explainer: small toy-network simulations testing what a modified version of the REBUS / entropic brain theory predicts.

`index.html` is the published page, a single self-contained file served by GitHub Pages. It is built and checked in a separate private repository and copied here only when approved; do not edit it here.

Toy networks and synthetic data: nothing here is evidence about brains or therapy.
